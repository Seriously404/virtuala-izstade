# Virtuālā izstāde - tīmekļa vietnes izstrādes projekts

## 1. projekta apraksts
Projekts ir izstrādāts prakses laikā, izmantojot HTML5, CSS3 un JavaScript.
### projekta mērķis
Projekta mērķis ir izveidot interaktīvu un responsīvu tīmekļa vietni - virtuālu izstādi par izvēlēto tēmu.
### Izstādes tēma
Videospēļu vēsture
### Izstādes nosaukums
Spēļu pietura

## 4. Izmantotās tehnoloģijas
HTML5 - tīmekļa vietnes struktūras izveidei
CSS3 - tīmekļa lapas dizaina izveidei un vizuālajam izkārtojumam, izmantojot flexbox un grid.
JavaScript - interaktīvu funkciju un animāciju izveidei.
GitHub - projekta failu versiju kontrolei un komandas sadarbībai.

## 5. Tīmekļa vietnes funkcionalitāte
### Izstrādātajā tīmekļa vietnē ir:
Galvene un navigācijas izvēlne
Izstādes apraksts
Attēlu galerija, kurā ir 19 attēli
Interaktīvs karuselis, kurā ir kopā 38 attēli, starp 19 priekšplāna un 19 fona attēliem
Manuāla un automātiska attēlu pārslēgšana, ar 10 sekunžu intervālu.
Dizains veidots, lai atbalstītu dažādu izmēru ierīces
Lapas kājene ar autoru vārdiem un visiem informācijas un foto avotiem.

## 6. Projekta palaišana
1. Lejupielādējiet projekta failus vai klonējiet Github Repozitory:
git clone https://github.com/Seriously404/virtuala-izstade virtuala-izstade
